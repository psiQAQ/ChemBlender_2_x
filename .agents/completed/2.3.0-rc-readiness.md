## Dependency and Warning Boundaries

- The package contains only the approved Gemmi 0.7.5 CPython 3.13 Windows
  wheel (`ad1f72ffa24adbfaf259e11471f6f071a668667f6ca846051f3bfea024fd337d`)
  and RDKit 2026.03.3 CPython 3.13 Windows wheel
  (`f8bd59b24e128c9c70c975bfb1920cf610ba3096439a24ca2850eb861e767c48`).
- Gemmi remains an optional CIF adapter dependency and RDKit remains an
  optional molecular adapter dependency; neither object model crosses the
  vendor-neutral project/sidecar boundary.
- Windows can report cleanup warnings for loaded Gemmi/RDKit DLLs until the
  Blender process exits. Both product runs reached the explicit lifecycle PASS
  marker and exited 0; the warnings are not treated as success evidence.
- The smoke script intentionally exercises rejected UI operations and asserts
  their fail-closed result, so the expected operator `Error:` reports do not
  indicate a failed product gate.
