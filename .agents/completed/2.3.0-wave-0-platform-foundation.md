# ChemBlender 2.3.0 Wave 0 — Platform Foundation

## State

Completed and published as `v2.3.0-alpha.1`.

## Result

Wave 0 delivered the modular project model, Reader API 0.x, one authoritative
ProjectSession per `.blend`, transactional imports and multi-Scene links,
durable `.cbq`/View caches, explicit extension registration, Quick Import,
Project Browser, format-aware default views, and deterministic release
packaging.
