## Delivered Boundary

- ChemBlender 2.5.0 is a wheel-free Blender Viewer that keeps CBQ import/export, pure Mesh editing, Apply, View, animation, Cycles and saved-project recovery.
- `chemblender-prepare 0.1.0` is the external Standard `uv tool`; Blender stores one absolute `chemblender-prepare.exe` path and uses Worker Protocol v1.
- Standard includes NumPy, RDKit and Gemmi. Scientific/Fermi/critic2/QCEngine/provider routes remain explicit optional configuration.
- Public contracts are the 10-command CLI, 9-command GUI, Worker Protocol v1 and Reader API `1.0-rc1`; internal Python modules are not a stable SDK.
- The old 2.4 workflows are archived. English and Chinese daily SOPs and offline HTML are the maintained documentation surface.
