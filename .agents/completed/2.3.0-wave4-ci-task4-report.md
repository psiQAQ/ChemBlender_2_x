# Wave 4 CI Task 4 — Artifact Size and License Budget Report

## Result

Completed locally. `artifact_size_report.py` is standard-library only and
reuses the Task 1 ZIP-member validator without extracting outer or nested
archives to disk. Package CI now produces one five-file artifact: the ZIP,
checksum, `wheel-inventory.json`, `wheel-license-copy-list.json`, and
`artifact-size.json`. It generates and verifies all metadata before the sole
upload.

`verify_release_artifact.py` has explicit modes. `package-ci` requires a
budget path and recomputes package/metadata evidence; `release-assets` is the
explicit ZIP/checksum-only interface. The Release workflow consumes the former
mode for the exact package CI artifact.

`chemblender-2.3.0-alpha.1.zip` at `29,936,732` bytes with SHA-256
`605a2027adf7bd58af91b349150fffb7d8e11444b532448d5b794dedc7b3cc7e`.

member bytes: code `2,487,326`, resources `2,505,199`, wheels `26,888,752`,

largest outer member is the `24,618,400`-byte RDKit wheel, below the reviewed
`30,000,000`-byte member ceiling; the package does not contain the Task 4
scripts. Central-directory limits are checked before any outer or nested CRC
scan or member read.
