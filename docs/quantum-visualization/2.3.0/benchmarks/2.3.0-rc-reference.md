## Budget and regression policy

`ChemBlender/benchmarks/budget.json` is schema `2.0`. It maps each approved
limit to a required product measurement: five cold gates require `cold_p95` and
the cached trajectory gate requires `hot_p95`. Missing, failed, non-finite,
`Not Run`, diagnostic, wrong-scale, or wrong-cache reports fail closed.

Qualification additionally requires a 40-hex `source_commit`,
`source_dirty: false`, and nonempty exact Blender/RDKit/Gemmi runtime versions.
CI trend comparison requires candidate and baseline equality for CPU count,
machine, platform, processor, Python implementation/version, and all three
runtime versions. Interpreter path is excluded because controlled CI checkout
paths are not a performance property.

The Task 2 review policy remains p95 +15%. The boundary uses a tight floating
comparison: `0.1 -> 0.115` passes, while a materially larger value fails. Any
baseline or threshold change requires explicit review evidence.
